# Dr. D. Y. Patil Vidyapeeth (DPU) Brand & Slide Presentation Style Guide

## 1. Palette & Colors
- **Primary Brand Color**: `#002147` (DPU Navy Blue)
- **Secondary Accent**: `#C0392B` (DPU Crimson / Red)
- **Support Accent**: `#1E40AF` (Royal Blue)
- **Text Color**: `#0F172A` (Slate Dark)
- **Background**: `#FAFAFA` (Off-White)
- **Code Block Background**: `#1E1E2E` (Modern Dark Monokai/OneDark)
- **Code Block Text**: `#F8F8F2`
- **Muted / Subtitles**: `#64748B`

## 2. Typography
- **Slide Titles**: `Arial`, Bold, 28pt to 38pt
- **Body & Bullets**: `Segoe UI`, 16pt to 22pt
- **Code Blocks**: `Consolas`, Monospace, 14pt (never smaller than 14pt)

## 3. Dimensions & Margins
- **Aspect Ratio**: 16:9 Widescreen (1920x1080 px / 13.333" x 7.5")
- **Safe Margins**:
  - Left Margin: 1.5 inches (216px)
  - Right Margin: 1.5 inches (216px)
  - Top Margin: 1.1 inches (150px)
  - Bottom Margin: 0.8 inches (115px)

## 4. Placeholders & Layouts
- **Title Slide**: Layout 0 with Title, Subtitle, and Logo
- **Title & Content**: Layout 1 with Title, Body placeholder, Footer, and Slide Number
- **Two Content (Split)**: Layout 2 with Left and Right Content placeholders
- **Code / Lab Slide**: Layout 3 with Title, Content, and Footer
- **Closing Slide**: Layout 4 with Summary and Key Takeaways

## 5. Header, Footer & Logo
- **Header**: Official DPU Banner with DPU Emblem at top left (`dpu_logo.png`).
- **Footer**: `Dr. D. Y. Patil Vidyapeeth, Pune (Deemed to be University)` at bottom left, 10pt `Segoe UI`, color `#64748B`.
- **Slide Number**: Formatted at bottom right.

## 6. Code Block Constraints
- **Max Lines**: 14 lines per code block.
- **Max Width**: 60 columns without wrapping.
- **Minimum Font Size**: 14pt.
- **Syntax Highlighting**: Pygments OneDark / Monokai palette.

## 7. Diagrams
- **Max Nodes**: 7 nodes per diagram.
- **Max Words per Label**: 3 words.
- **Resolution**: 2x resolution PNG with text equivalent to $\ge 16$pt.
